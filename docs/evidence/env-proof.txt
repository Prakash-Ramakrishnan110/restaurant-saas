## 2. Process Verification & Environment Port Mapping

- **Database Port**: Configured dynamically via `POSTGRES_HOST_PORT` (defaults to `5433` for local service, or `5435` when running Docker Compose container). Both `fusion_saas` and `fusion_saas_test` are fully migrated with identical schemas.
- **Seeded Data**: All live API flows and data screens connect directly through Vite proxy (`127.0.0.1:5173 -> 127.0.0.1:8000 -> 127.0.0.1:5433`) against the database seeded with `python manage.py seed`.
- **Pure Zero-Mock Invariant in Production Code**:
  Non-test frontend code in `frontend/src` contains **ZERO** occurrences of `mock` or `faker` (verified via `git grep -n -i -E "mock|faker" -- frontend/src ':!*.test.*'`).
- **Network Route Mocking in E2E**:
  Playwright tests utilize `page.route` intercepts exclusively for isolated negative/edge-case tests (e.g. simulating 429 rate limit countdowns, offline state banners, and role-boundary validation) to ensure tests run deterministically and fast without polluting the primary shared seed database.
