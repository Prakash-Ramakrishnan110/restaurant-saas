## 3. Playwright & Test Execution Clarity

- **No Second Conflicting Stack**: The Docker PostgreSQL instance (`fusion_postgres` on port 5435) is the single relational database utilized for all operational data.
- **Seeded Data**: All live API flows and data screens connect directly through Vite proxy (`127.0.0.1:5173 -> 127.0.0.1:8000 -> 127.0.0.1:5435`) against the database seeded with `python manage.py seed`.
- **Pure Zero-Mock Invariant**: Non-test frontend code in `frontend/src` contains **ZERO** occurrences of `mock` or `faker` (verified via `git grep -n -i -E "mock|faker" -- frontend/src ':!*.test.*'`).
- **Network Route Mocking in E2E**: Playwright tests utilize `page.route` intercepts exclusively for isolated negative/edge-case tests (e.g. simulating 429 rate limit countdowns, offline state banners, and role-boundary validation) to ensure tests run deterministically and fast without polluting the primary shared seed database.
