# ServeMyFood: Prompt 4A Menu Core Test Map & Verification Invariants

This document maps all Prompt 4A Menu Core behavioral specifications to their exact backend unit/isolation tests, frontend Vitest component tests, and Playwright E2E browser flows.

---

## 1. Backend Test Map (`backend/apps/menu/tests/`)

### A. RBAC Matrix Tests (`test_menu_rbac_matrix.py`) — 150 Parameterized Test Cases
6 Roles (OWNER, BRANCH_MANAGER, CASHIER, KITCHEN, WAITER, PLATFORM_ADMIN) tested across 25 distinct Menu endpoints:
- **`CategoryViewSet`**: list, create, retrieve, update, partial_update, destroy, reorder
- **`MenuItemViewSet`**: list, create, retrieve, update, partial_update, destroy, bulk_create
- **`MenuItemVariantViewSet`**: list, create, retrieve, update, partial_update, destroy
- **`BranchItemAvailabilityViewSet`**: list, retrieve, toggle_availability, bulk_availability
- **Key Invariant**: Role `WAITER` receives `403 Forbidden` on ALL write and availability endpoints (including GET `/availability/` and POST `/availability/bulk/`).

### B. Image Safety & Model Constraints (`test_menu_models_and_services.py`) — 6 Suites
- **`test_image_safety_rejections`**:
  - Rejection of SVG files (MIME/extension)
  - Rejection of disallowed extensions (`.exe`, `.pdf`, `.html`)
  - Polyglot / disguised malware payload detection
  - Decompression bomb detection (PIL safety limits)
  - Animated GIF / WebP rejection
  - Enforced minimum dimensions (400x300px)
- **`test_image_processing_and_exif_strip`**:
  - EXIF / GPS metadata stripped on ingest
  - Card (800x600 WebP) and Thumbnail (300x300 WebP) generated
  - Center-weighted smart crop applied
- **`test_image_replacement_and_storage_quota`**:
  - Replacing an image automatically purges old storage artifacts from disk
  - Strict tenant storage quota enforced (400 `IMAGE_STORAGE_QUOTA_EXCEEDED` on limit reach)
- **`test_atomic_bulk_creation_rollback`**:
  - Atomic database transaction rolls back all created items if any row in batch fails
- **`test_model_validation_and_clean`**:
  - Positive integer price enforcement in paise
  - Unique category name per tenant validation
  - Non-negative prep time and sort order

### C. Isolation & Filter Tests (`test_menu_endpoints_and_isolation.py`) — 9 Suites
- **`test_waiter_cannot_view_or_toggle_availability`**: Waiter receives 403 on availability views
- **`test_category_tenant_isolation`**: Cannot assign item to Category belonging to another Tenant (raises 400 `CATEGORY_NOT_FOUND`)
- **`test_item_tenant_isolation`**: Tenant A cannot read, update, or delete Tenant B items
- **`test_price_update_audit_log`**: Changing `base_price_paise` creates an immutable `AuditLog` entry
- **`test_tamil_search_filter`**: Search parameter matches English `name` or Tamil `name_ta`
- **`test_menu_constant_query_count`**: Constant O(1) query count (8 queries) when retrieving 200 menu items across categories
