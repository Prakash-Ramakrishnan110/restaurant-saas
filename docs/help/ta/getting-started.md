# தொடக்க வழிகாட்டி மற்றும் கணக்கு அமைப்பு

உங்கள் உணவக கணக்கு Fusion Engine மூலம் உருவாக்கப்படுகிறது.

1. உங்கள் மின்னஞ்சல் மற்றும் தற்காலிக கடவுச்சொல் மூலம் உள்நுழையவும்.
2. முதல் உள்நுழைவில் புதிய கடவுச்சொல்லை அமைக்கவும்.
3. **{{nav:Onboarding}}** வழியாக 7 படிகளை முடிக்கவும்.
4. **{{nav:Branding}}** பகுதியில் லோகோ மற்றும் பெயரை அமைக்கவும்.
