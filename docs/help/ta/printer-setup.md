# பிரிண்டர் அமைப்பு மற்றும் சரிசெய்தல்

1. உங்கள் 58mm அல்லது 80mm பிரிண்டரை இணைத்து டிரைவரை நிறுவவும்.
2. **{{nav:Printers & Devices}}** பகுதியில் காகித அளவைத் தேர்வு செய்து **Print Test Slip** அழுத்தவும்.
3. Chrome அச்சு அமைப்பில் **Margins: None**, **Headers and footers: Off**, **Scale: 100%** என அமைக்கவும்.
