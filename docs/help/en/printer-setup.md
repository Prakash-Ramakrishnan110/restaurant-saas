# Thermal Printer Setup & Troubleshooting

1. Connect your 58mm or 80mm thermal printer via USB, Ethernet, or Wi-Fi and install its OS driver.
2. Set paper width (`58mm` or `80mm`) in **{{nav:Printers & Devices}}** and click **Print Test Slip**.
3. In Chrome print dialog: set **Margins: None**, **Headers and footers: Off**, **Scale: 100%**.
4. For kiosk silent printing, launch Chrome with `--kiosk-printing` (must be tested on your physical printer first).
