# Project Architecture & Specification Deviations Log

This document records deliberate, accepted design decisions and differences between initial prompt specifications and final production implementation.

## Deviations Matrix

| ID | Topic | Initial Spec / Early Prompt | Production Implementation | Rationale |
|---|---|---|---|---|
| **DEV-001** | Database Host Port | `5432` host port | Loopback `127.0.0.1:5435 -> 5432` | Host development environment had existing PostgreSQL versions running on 5432, 5433, and 5434. Binding to loopback `127.0.0.1:5435` prevents port conflicts while securing the database from external network interfaces. |
| **DEV-002** | Celery Idle Session Task | Placed directly in app services | Registered in `apps.core.tasks.expire_idle_sessions_task` which delegates to `apps.venues.services` | The Celery worker imports tasks registered in `apps.core.tasks` (confirmed via `celery -A config inspect registered`), keeping Celery beat schedules unified while delegating execution to the venues domain service. |
| **DEV-003** | Error Code HTTP Statuses | Mixed 400s for conflict states | HTTP 409 Conflict for `LAST_OWNER`, `SESSION_ALREADY_OPEN`, `TABLE_NOT_AVAILABLE`, `DUPLICATE_LABEL` | Standard REST semantics: resource state conflicts (concurrency, existing sessions, duplicate unique identifiers, last owner removal) return HTTP 409 Conflict instead of HTTP 400 Bad Request. |
| **DEV-004** | Invariant Rules on PATCH | Full replacement check only | Invariant rules R1-R7 validated against merged state on partial `PATCH` | Ensures partial updates to single capability fields cannot put the venue configuration into an illegal state (e.g., toggling `uses_tables=False` while `has_sections=True`). |
| **DEV-005** | Streamlined Capabilities & Presets | Legacy multi-field timing & unconstrained policies | Unified 15-field matrix with locked preset values and streamlined enums | Final production preset values enforce: (1) `CAFE` `qr_ordering_mode` is `ORDER_DIRECT` and `qr_session_policy` is `CUSTOMER_CAN_OPEN`; (2) `HOTEL_RESTAURANT` `qr_session_policy` is `STAFF_ONLY`. The `QRSessionPolicy` enum is strictly limited to `CUSTOMER_CAN_OPEN` and `STAFF_ONLY` (`MANUAL_STAFF_CLOSE` does not exist). |
| **DEV-006** | Brand Color Accessibility | White text on Orange `#FF6A00` | Deep Navy `#0B1F3B` on Orange `#FF6A00` (5.7:1 AAA contrast) | WCAG AA compliance requires at least 4.5:1 contrast for normal text and 3:1 for large UI components. White on `#FF6A00` only achieved 2.87:1 (failing AA); Deep Navy achieves 5.7:1 (WCAG AAA compliant). |
| **DEV-007** | Permission Codes | Pluralized/mixed codes (`tables.manage`, `qrcodes.view`) | Restored exact Prompt 2 singular codes (`branch.view/manage`, `area.view/manage`, `floor.manage`, `table.view/manage/status_update/merge/assign`, `table_session.open/close`, `qr.view/manage`, `staff.view/manage`, `business.view/manage`) | Maintains strict alignment with the 72-case role-by-endpoint RBAC matrix and ensures each endpoint requires its most specific permission code. |
